# FORGE Executive Office | Project Showcase

> A personal AI operating workspace for planning, oversight, and approval-gated automation.

## The problem
Projects, tasks, and information often live across disconnected services. FORGE explores an AI-assisted workspace where planning, execution proposals, and owner approvals can happen in one place.

## What the project demonstrates
- Executive-style AI conversations and project planning
- Mission tracking and persistent context
- Multi-perspective boardroom review
- Approval workflows for consequential actions
- Integrations designed around read-only access and explicitly approved writes

## Engineering approach
The repository documents a Next.js application with integrations for AI models and external tools. Its safety model distinguishes inspection from external changes and requires approval for sensitive operations.

## Current maturity
An evolving engineering project. Features described in the repository are implementation goals or documented capabilities, **not independently verified live production services**. Do not publish API keys, owner keys, access tokens, or private workspace data.
